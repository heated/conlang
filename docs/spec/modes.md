# Mode Subsystems — Tier-2 Specification

**Version:** 0.1.0-draft · **Status: NOT FROZEN.** Mode particle
assignments are **PROVISIONAL** until conlang-jbw fixes the particle
budget; the digit-pair code itself is frozen with the core (SPEC §10).

Encoders/decoders: `tools/modes.py`. Every worked example below is
generated by `python3 tools/modes.py examples` and asserted by
`tools/test_modes.py` — the doc cannot drift from the code.

## 1. Design principles

1. **Payloads live on the anti-check side** (SPEC §4.2). Adopted as
   policy: with dates at two digit-pair syllables (learnability beats
   monosyllable dates — Edward directive), no mode needs more than the
   200 content-shaped payload points per syllable, so the restriction
   costs nothing and buys machine-layer self-flagging. The length-deaf
   qualification stands: mode *boundaries* carry the burden for
   listeners who cannot hear register.
2. **Everything is the one digit-pair code.** No month tables, no hour
   tables to memorize: dates and coordinate digits reuse the SPEC §10
   pairs verbatim; time adds two orthogonal rules to the same grid.
   Learning cost of all core modes ≈ learning the digit pairs once.
3. **Modes win for payloads of two or more syllables**; casual speech
   uses lexical number words for small counts (Zipf assignment gives the
   most frequent numerals lexical forms).

## 2. Mode particles (PROVISIONAL)

| particle | canonical | mode |
|----------|-----------|------|
| h-u | `huu` | number: digit pairs follow, base-100, big-endian |
| h-o | `ho` | date: [year pairs] + month pair + day pair |
| h-i | `hii` | time: one hour×quarter syllable [+ minute-offset pair] |
| h-e | `he` | spell: one letter-name syllable per letter |
| h-e-n | `hen` | phonetic mode — reserved, mechanism only in v0.1 |
| h-i-n | `hin` | coordinates — reserved, design sketched in §7 |
| h-a-s | `haas` | mode close (optional in casual speech) |
| h-o-s | `hoos` | mode close + checksum syllable follows |

Eight of the twenty particle slots. conlang-jbw budgets the remaining
twelve for grammar; if the grammar overflows, mode particles migrate to
coda-bearing slots first (they are rarer than core grammar particles).

## 3. Numbers

`huu` + one payload syllable per digit pair (odd digit counts left-pad
with zero), positional base-100, big-endian. Negative numbers, decimals,
and arithmetic notation are deferred to a future math mode.

## 4. Dates

`ho` + optional year (digit pairs) + month pair (01–12) + day pair
(01–31). Field order is fixed big-endian (Y-M-D); a yearless date is
recognized by payload length (2 pairs vs 4+).

## 5. Times

One syllable per Edward's directive, as a pure grid over the digit code:

- **onset** = digit onset of the hour's last digit (SPEC §10 tens row)
- **coda** = hour tens: ∅ = 0x, n = 1x, s = 2x
- **vowel** = quarter: a = :00, e = :15, i = :30, o = :45 (u reserved)

Exact times append a minute-offset pair (00–14); seconds another pair.

## 6. Spell mode

`he` + one payload syllable per letter. Letters whose sound exists as an
onset use onset + e (`pe te ke me ne se le we je ce`); the five vowel
letters are payload-register h-syllables (`ha he hi ho hu` — legal as
payloads because payload space includes the h column); remaining letters
take a nearest-sound onset + a (b=`pa` d=`ta` g=`ka` f=`wa` r=`la`
x=`sa` y=`ja` z=`su` q=`ku` v=`we` h=`han`). Table is normative data in
`tools/modes.py`, PROVISIONAL pending a naive-listener confusion pass.

## 7. Coordinates (reserved sketch)

`hin` + hemisphere marker (payload-h syllable) + degree digit pairs per
axis. Not normative in v0.1; the encoder is deliberately unimplemented
until the checksum register profile (§9) is settled, since coordinates
are a safety-register payload almost by definition.

## 9. Error budget and the checksum profile

The digit code deliberately uses the full payload grid, so in-mode
substitutions are dense. Generated analysis
(`python3 tools/modes.py confusion`), over all 1,600 single-channel
corruptions of the 100 digit-pair syllables:

- **200 (12.5%)** break the digit grammar (coda s/l) — caught by the
  mode parser outright.
- **1,400 (87.5%)** land on another valid digit pair. Of these, **840
  (60%)** flip the payload register (covered-pair substitutions, e.g.
  c/s = digits 0↔6): detectable by machines and register-sensitive
  listeners, silent for length-deaf listeners.
- The **checksum** is therefore load-bearing, not decorative:
  position-weighted sum of digit-pair values mod 97 (IBAN precedent),
  one payload syllable after `hoos`. Catches all single-pair
  substitutions and all adjacent transpositions.

**Register profiles:** casual speech — checksum optional, repair
("what?") does correction. Careful/readback — repeat the payload.
Safety-critical (aviation-style) — checksum mandatory, and the
known-weak digit cells (SPEC §10: coronal-i column, glide-fusion cells,
final-n units) get fortified realizations; a dedicated careful-register
digit readout (distinct redundant digit names, "niner"-style) is an open
design item tracked here.

## 10. Relation to the frozen core

Modes consume: the digit-pair assignments (SPEC §10, frozen), the
anti-check complement (SPEC §4.2, frozen), and eight provisional
particle slots (not frozen). Nothing in this document constrains the
lexicon beyond what SPEC v0.1 already states.
