# RZ bootstrap scenarios — the decision packet (conlang-9g5)

Program lane C, first in sequence (program.md): the chosen scenario
weights the GZ→RZ mining audit (conlang-faj). Evidence base:
zonal-auxlang-survey.md §5 (growth/stall factors, measured) and
partial-systems.md §1 (the adoption pattern for sub-languages:
*"partial systems win via mandated trained domains, institutional
written conventions, or maintained broadcast registers — never via
individual study decisions"*; full receptive languages win via
receptive-first proof + one standard + production tooling + a media
moment + legitimacy tokens — all five present in Interslavic, the
only zonal lang with a measured growth curve).

Scenario = (audience, first artifact, channel, success metric, what
it demands from the spec).

## S1 — The graded-reader funnel ("read it today")

- **Audience**: Romance-L1 curious readers (ES/PT/IT/FR internet
  publics; ~800M potential zone readers).
- **Artifact**: a polished web reader — the six-register parallel
  corpus as progressive stories, inline gloss on tap, an embedded
  self-scoring cloze ("see how much you understood with zero
  study"). The Interslavic move: pair the claim with a number.
- **Channel**: language-YouTube / r/languagelearning / HN via S2.
- **Metric**: zero-study cloze on organic visitors (target: match
  or beat Interslavic's 84%); % of visitors who finish a story.
- **Spec demand**: text quality, false-friend screen rigor, error
  absorption (readers become writers with fewer wrong-note
  outputs), curriculum ("half the grammar in the first hour" as the
  hook). Needs NOTHING new from the spec — it monetizes what RZ
  already is.

## S2 — The thesis moment (engineering audience first)

- **Audience**: engineers, conlang community, HN — people who adopt
  *methods*.
- **Artifact**: the published thesis (lane D) with interactive
  demos: the number mode, chording, the ledger, the absorption
  declarations. "A language engineered for learnability, with
  receipts."
- **Channel**: the paper + site; this IS the media moment attached
  to a story (survey factor 3), and it recruits the scarce
  resource — writers/contributors (survey: receptive languages
  bottleneck on writers).
- **Metric**: contributors and derived works (forks, ports of
  toolkit entries, corpus submissions), not raw readers.
- **Spec demand**: measured claims, honest [H] labels, demo
  tooling, reproducibility. The survey's warning applies: the
  moment only converts if infrastructure exists to catch it → S5
  must be staged before firing S2 loudly.

## S3 — RZ-lite transactional on-ramp

- **Audience**: travelers in Romance countries; hospitality staff.
- **Artifact**: the RZ-lite card (~200 words, 10 patterns, an
  afternoon) + signage/menu kit.
- **Metric**: productive use after one afternoon; venue pickups.
- **Spec demand**: rz-lite.md is already built; strict-subset
  property maintained.
- **Risk (from the evidence)**: this is an individual-study partial
  system — the class that historically stalls without an
  institution. Positioned as S1's *on-ramp page*, not a standalone
  bet.

## S4 — Civilian readback / safety register

- **Audience**: trained domains (pharmacy, support lines,
  dispatch) — the STE/NATO adoption route.
- **Artifact**: one-page readback protocol card (modes + checksum +
  confirmation micro-vocabulary).
- **Metric**: error-rate reduction in a controlled readback task.
- **Spec demand**: modes complete (bcq), repair mode, human-factors
  validation FIRST (safety positioning removed 2026-08-15 pending
  exactly that).
- **Risk**: needs a mandate-holder; slowest funnel; cannot be the
  primary bet. Kept armed as the institutional wedge.

## S5 — Production-tooling flywheel (writer-first)

- **Audience**: the first dozens of would-be RZ writers.
- **Artifact**: interslavic.fun analog — dictionary, conjugator,
  false-friend linter, chorded/phone input.
- **Metric**: texts published per month by non-founders.
- **Spec demand**: machine-readable lexicon + grammar (largely
  true already: tools/ parses everything).
- **Evidence**: survey factor 4 — production tooling is a
  first-class growth mechanic, not an accessory.

## The packet (recommendation — Edward's call to confirm)

**Primary: S1, launched through S2, with S5 staged as the catcher.**
This replicates three of Interslavic's five growth factors:
receptive-first proof (S1's cloze number), a story-shaped moment
(S2 — and note the [H]: *that a thesis publication functions as a
media moment is a hypothesis*; Interslavic's moment was a feature
film), and production tooling (S5). The remaining two factors are
carried by existing beads and become explicit milestones of this
packet: **one standard with a named authority** (governance +
versioned spec, bead 70m — must be in place before S2 fires, since
the moment converts inbound interest into a standards-war if
governance is absent) and **legitimacy tokens** (compounding
milestones: the published paper itself, an ISO 639-3 application
when community size warrants, a published reader). S3 folds into
S1 as its on-ramp page. S4 parks until human-factors validation
and an institutional partner exist.

**Success metric for the program**: (1) a measured zero-study cloze
number from organic readers, (2) ≥ a handful of non-founder writers
producing text with the tooling. Both are post-human-testing-gate;
until then the metric is artifact readiness.

**Mining-audit weights this implies** (conlang-faj):

| feature class | weight | why |
|---|---|---|
| reader-facing quality: texts, false-friend rigor, absorption, curriculum | HIGH | S1 is the product |
| measured-claims machinery: ledger, cloze instrument, honest labels | HIGH | S2 credibility |
| writer/production tooling incl. chording | MEDIUM-HIGH | S5 catcher; survey factor 4 |
| modes beyond numbers, repair register | MEDIUM-LOW | S2 demo value; S4 core but S4 is parked |
| display script, GZ-side polish | LOW | S2 demo garnish; owns no funnel |

Gate note (human-gates): the primary-scenario pick shapes what RZ
becomes → Edward's call. The audit proceeds on these weights
PROVISIONALLY; if Edward picks differently, re-weight before any
non-reversible adoption.
