# Conversation-repair mode (exploration, 2026-08-22, conlang-i78)

The modes machinery (numbers, dates) engineered the *payload* side
of noisy conversation. This explores the *protocol* side: what
aviation and maritime radio learned about keeping two error-prone
speakers synchronized — readback/hearback, "say again",
"correction", standard spelling — reduced to a particle set that
lives in the same silent-h hole as the number mode. Documented
aviation result: the readback/hearback loop plus standard
phraseology cuts communication-caused incidents dramatically
[D — TODO-verify at paper-citation time]; L2↔L2 auxlang speech is
exactly the noisy, no-shared-intuition channel that protocol was
built for.

## 1. The protocol particles (functions first; forms at spec bump)

Seven functions, each one particle, all h-onset (pronounced [h],
frame register, same phonetics deal as `hu`):

| function | aviation ancestor | semantics |
|---|---|---|
| HAIL | "do you read" | open channel / are you receiving |
| SAY-AGAIN | "say again" | repeat your last utterance |
| CORRECTION | "correction" | disregard last chunk; replacement follows |
| CONFIRM | "confirm" | I request verification of what follows |
| READBACK | "read back" | I will now repeat what I heard (opens the careful-register echo; pairs with the number mode's checksum) |
| SPELL | "I spell" | letter-by-letter mode opens (§2) |
| SLOW | "speak slower" | rate/complexity downshift request |

Concrete syllable forms are deliberately NOT pinned here — the
number mode's frame particles (hu + separator) come from the same
h-inventory and all get chosen together at the spec bump
(conlang-3mq) under one digitgen-style spacing audit, so the
repair particles can't collide with the number frames they will
often flank ("READBACK hu ki…").

Learner cost: seven particles + the readback discipline the number
mode already teaches ≈ **+~1h, cohort-flat** [H]. Like every mode,
it is optional machinery: conversation without it is just
conversation.

## 2. Spell-mode is acrophonic — ICAO's move at zero vocab cost

ICAO doesn't name letters (bee/dee/vee collapse over radio); it
speaks *words* (bravo/delta/victor). RZ can do the same with words
the learner ALREADY knows: SPELL + a known content word per
letter, initial = the letter. Feasibility measured on the corpus:
every RZ letter has attested candidates. Draft table (2+ syllable
words preferred; number words excluded — they belong to the number
mode; pairwise audit pending at spec bump):

> a agosto · b basse · c cafe · d demanda · e energia · f forte ·
> g governo · i italiano · j jornal · l lingua · m matina ·
> n norte · o oficina · p programa · q — GAP (only que/qui/quando
> attested; coin or accept `quanto`) · r romance · s stacion ·
> t tecnico · u urgente · v viajator · z zonal

The multi-syllable words are the redundancy — that's why ICAO
words survive noise where letter names don't. Cost: ~0h (the words
are the lexicon's own; only the convention is new).

## 3. Why this belongs in the portfolio

The modes thesis was that engineered subsystems port everywhere
(GF native, RZ convention, English wedge). Repair is the purest
case: the protocol is language-independent (aviation runs it over
English but owes it nothing), so the same seven functions drop
into GF (h-row), GZ (reserved escape onset), and the
modes-in-English card (as phrases). It also completes a stack: the
humility screen prevents confusions at *assignment* time, the
codebook spaces them at *signal* time, and repair mode recovers
the residue at *conversation* time. Three layers, one error
budget.
