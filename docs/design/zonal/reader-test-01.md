# Reader test 01 — Edward, cold read (2026-08-13)

**Subject profile**: English-L1, *out-of-zone* (RZ targets Romance-L1
readers; an English reader accesses only the shared Latinate stratum).
Read texts A (narrative) and B (conversational) cold, "not that
carefully"; marked words that felt unclear.

**Self-reported result**: "could kinda understand but not the
specifics. i wasnt blocked per-se, just only kinda knew what was
going on" — **gist yes, specifics no**.

## Marks

- **Text A** (9 / 106 words): disputava, sobre, qui, era, forte,
  quando, viajator, facer, manto
- **Text B** (9 / ~30 words): vole, prender, placer, io, conoce,
  sitio, cerca, aqui, alora

## Per-word classification

| word | in-zone status | for EN readers | action |
|---|---|---|---|
| disputava | solid (disputar everywhere) | stem transparent (dispute), the `-ava` ending obscures it | none; note: invariant verb endings are out-of-zone noise |
| sobre | solid (Ibero .65 + IT sopra) | opaque | none |
| qui, era, quando, aqui, io | zone bedrock | opaque / false-friend (era=epoch) | none — this is what out-of-zone reading costs |
| forte | solid | EN has *forte*; sense uncertainty anyway | none |
| viajator | solid compromise coinage | half-visible via *voyager* | none |
| facer | known hard case (reflexes diverged: hacer/fazer/fare/faire) | opaque | keep; watch in-zone cloze |
| manto | solid | *mantle*, half-visible | none |
| prender, placer, conoce | solid | distant derivatives only | none |
| sitio | solid; chosen partly FOR EN *site* | marked anyway (context) | none |
| **cerca** | **weak!** Ibero-only; IT *circa* is a false friend ("approximately") | opaque (*circa* misleads) | **fix: → `proxime`** (ES próximo / PT próximo / IT prossimo / FR proche / RO aproape / EN proximity — wins on every axis) |
| **alora** | **questionable**: Italo-French (.30); Ibero majority says *entonces/então* | opaque | flagged §9: recipe weights say `entonce`; alora is prettier — decide with in-zone cloze data |
| vole | already an open §9 question (voler vs querer) | opaque | +1 data point, though from out-of-zone |

## Findings

1. **Register stratification is real and steep.** Conversational
   marks ran ~3× denser than narrative (9/30 vs 9/106). Everyday
   vocabulary is exactly where the Romance languages diverged from
   each other AND where the English-Latinate overlap vanishes.
   Prediction: in-zone cloze scores will also be lowest on register B.
   The lexicon iteration budget should go there first.
2. **Out-of-zone reach is gist-level, as theory predicts.** An
   English reader rides the Latinate stratum to the topic but loses
   the specifics carried by zone-internal bedrock (era, quando, qui,
   function words). RZ's implicit English reach is real but shallow.
   Consequence adopted: recipe tie-break #4 (below) — on otherwise
   equal candidates, prefer the form with an English/international
   Latinate cognate, since English is the world's dominant L2 and the
   out-of-zone gist channel is nearly free to widen.
3. **Gist and specifics must be scored separately.** "Not blocked
   per-se, only kinda knew what was going on" is precisely the
   distinction the instrument must capture: cloze blanks measure
   specifics; the one-line summary item measures gist. Both go in the
   published numbers (cloze-test-v0.md updated).
4. **One live fix applied** (`cerca` → `proxime`), one deferred to
   data (`alora`), one reinforced open question (`voler`). The
   false-friend screen gains a second confirmed catch (IT *circa*).
