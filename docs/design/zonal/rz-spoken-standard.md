# The spoken layer: a reference realization for zone-wide listening
(exploration, 2026-08-22, conlang-i78)

## The gap this fills

Every receptive-first argument in this repo is about READING. The
scenarios need a voice: S2 demo videos, the S6 record video, any
media moment speaks. And listening is the harder channel — the
intercomprehension literature consistently finds Romance
cross-comprehension much higher written than spoken (the classic
case: ES↔PT, near-free in writing, sharply asymmetric and lossy in
speech) [literature-supported; TODO-verify against primary sources
before publication]. Orthographic cognates survive sound changes
that acoustic forms do not. RZ's zone-shared object is the *written
skeleton* — so the spoken standard's job is to keep that skeleton
audible.

## The principle: orthography-transparent realization

RZ prescribes, for its broadcast/reference voice, that **the
acoustic form is a faithful rendering of the written form**: every
letter audible (except the one declared silent `h`), every vowel
cardinal, every syllable given its full duration. The listener is
never asked to undo a reduction, an elision, or a stress-timing
compression to recover the spelling their L1 recognizes. This is
the spoken analog of the first-contact invariant.

Concretely (extends rz-grammar §1's reference values):

1. **Vowels: five cardinal qualities, NO reduction, ever.** This is
   the load-bearing rule. PT- or CAT-style vowel reduction (or
   FR-style schwa) would collapse exactly the material IT/ES
   listeners need. Unstressed syllables keep full quality.
2. **Syllable-timed rhythm** (ES/IT-like), not stress-timed —
   unstressed syllables stay long enough to carry their cognate
   information.
3. **Stress exactly by the two-pattern rule** (penult on
   vowel/-s/-n, else final) — the rule is the same one readers
   derive, so the acoustic and written word-shapes agree.
4. **Consonants: reference value + tolerance band.** The grammar
   already declares c/g softening with "L1 variants tolerated";
   generalized here as an explicit asymmetry:
   - **production standard (broadcast/media): the reference value**
     — c→/ts/, g→/dʒ/ before e,i; z=/ts/; v=[v]; any clear rhotic;
     ni/li = /ɲ ʎ/ intervocalically;
   - **perception standard: the band** — /s θ tʃ/ for soft c,
     /ʒ x/ for soft g, [b β] for v, etc. are all legitimate
     RZ-with-an-accent, absorbed exactly as rz-error-absorption
     absorbs grammar variants. Accents are absorbed; the broadcast
     voice is prescribed.
5. **Media default is the graded-listening register**: deliberate
   pace with clean pauses at clause boundaries (precedent: the
   "news in slow X" genre, and slow-register audio is standard
   practice in receptive-language media). Fast natural speech is
   not wrong; it is simply not the on-ramp artifact.

The worst cell, named: soft `g` diverges hardest across the zone
(ES /x/, FR-PT /ʒ/, IT /dʒ/) — no reference value can be acoustically
near all three. The reference /dʒ/ rides IT plus the international/
English stratum; ES listeners carry the widest gap. This is a known
cost, not a solved one.

## Pricing

- **First-contact tax: zero for readers** (nothing written changes)
  and the *reference realization is itself the zero-study listening
  on-ramp* — its value for listeners is the whole point, and it is
  unmeasured [H].
- **Learner cost: ~0.** Producing the reference voice is the same
  "pronounce the spelling" rule learners already get for reading
  aloud; the tolerance bands mean their accent was already legal.
- **Gate class: agent-callable** (pure-upside, reversible, no
  surface change) — adopted as the standard for any recorded RZ
  artifact; noted in rz-grammar §1's territory but living here
  until it earns a grammar line.

## Measurement (ARMED, like all human gates)

- **Listening cloze**: the fable, recorded in the reference
  realization, zero-study Romance-L1 listeners — the spoken sibling
  of the reading cloze, same non-inferiority framing, run when
  human testing opens.
- **Stimulus A/B, buildable now with TTS**: reference realization
  vs a deliberately reduced/stress-timed render of the same text —
  the stimuli need no subjects; the comparison does.

## Toolkit entry (portable)

*Separate the production standard from the perception standard.*
Any auxlang can prescribe one broadcast realization (orthography-
transparent, unreduced, syllable-timed) while absorbing the full
band of L1-accented realizations as legitimate — mirroring
error-absorption on the phonetic axis. Portable wherever the
language's shared object is its written form — which is true of
every zonal auxlang, since zones share spelling far better than
they share sound systems.
