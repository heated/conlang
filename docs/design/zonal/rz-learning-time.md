# RZ learning-time breakdown [H — model estimates, zero subjects]

Itemized, per cohort, hours to functional use of each component.
Anchors (TODO-verify): FSI ~600-750h Spanish for EN L1; Esperanto
~150-200h conversational; Interlingua read-at-sight for Romance L1.
Components are separable: a learner can stop after any row and have
something usable (reading-only RZ is a real endpoint).

| component | Romance L1 | English L1 | non-Euro L1 |
|---|---|---|---|
| receptive reading (Latin alphabet) | ~0-2h (sight) | ~5-15h | ~150-250h (vocab is the wall) |
| grammar (invariant verbs, -va past, va+inf, es/sta, clitics, negative concord) | ~5-10h | ~10-20h | ~20-30h |
| lexicon, productive (~380 core + false-friend flags) | ~10-25h | ~40-80h | ~150-250h |
| pronunciation & production practice | ~5-15h | ~20-40h | ~30-60h |
| **number mode (tentative)** | **~2h casual, +2h readback** | **~2-4h** | **~3-5h** |
| display script, reading (featural letterforms + logograms) | ~3-5h | ~3-5h | ~3-5h |
| chording (optional; zero-exception theory) | ~5-10h to competence; speed = weeks of practice | same | same |
| **productive total (speech, no options)** | **~20-50h** | **~80-150h** | **~350-550h** |

Notes: (1) the number mode is nearly cohort-flat — it is the one RZ
component whose cost does NOT scale with distance from Romance,
because its material is engineered; six of ten tens-onsets are
additionally guessable for the Romance cohort. (2) The display
script and chording rows are flat for the same reason. (3) The
non-Euro column is RZ's honest weakness — nothing in the design
helps that cohort with the lexicon, which dominates their total
(that column is the GZ/GF-N case). (4) Reading-only Romance-L1 RZ
remains the headline: functional in hours.
