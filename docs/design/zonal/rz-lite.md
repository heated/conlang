# RZ-lite: the pan-Romance transactional register (extraction v0)

From partial-systems.md candidate #2: ~200 words + ~10 patterns, no
morphology beyond plural `-s`. The Lingua Franca's designed
descendant. Everything below is a strict subset of RZ (any RZ-lite
text is valid RZ), so it doubles as RZ's on-ramp.

## The ten patterns

1. Noun phrase: `(le/un) N (Adj)` — `le sopa calde`
2. Plural: `+s/-es` — `dos cafes`
3. Existence/location: `X sta aqui / en Y` — `le banio sta ala`
4. Want/request: `Io vole X` / `X, por favor`
5. Price/ask: `Cuante costa X?` — answer `N euros`
6. Yes/no question: statement + `?`
7. Negation: `no` + V — `no comprende`
8. Imperative: bare verb — `Corta`, `Serve`, `Atende`
9. Possession/of: `X de Y`
10. Greeting/social frame: `Bon dia / Gracias / Pardon / Adio`

## Core vocabulary (~180, all from rz-lexicon/core-conversational)

Function: `le les un e o no si que de a en con por sobre cuante aqui
ala proxime`. Social: `bon dia, bon nocte, gracias, por favor,
pardon, adio, benvenite`. Transaction: `vole, prende, paga, costa,
debe, cambio, precio, euro, moneta, cuenta (bill; FLAG), mercato,
tenda`. Numbers 0–1000 (rz-grammar §8). Time: `hora, dia, hodie,
deman, matina, tarde, nocte` + days/months. Food: the food/drink
field + recipe register. Places: `stacion, hotel, banio, hospital,
farmacia, restaurante, porto, aeroporto, citate, via, ponte`.
Directions: `a destra (right; FLAG IT), a sinistra (FLAG IT — vs ES
derecha/izquierda: the direction pair is a hard zone split, both
flagged for cloze), directe, retorna`. People: `persona, senior /
seniora (address forms), infante, medico, policia`. Emergency:
`ajuta!, urgente, dolor, malade, perdite (lost), telefona`.
Adjectives: `grande, pequen, calde, frio, bon, mal, aperte, cluse
(closed; FLAG), libre, ocupate, rapide, lente`.
