# Modes in English — the convention note (Track E, rung 1)

Bead conlang-0i7. The channel language's mode subsystem (spec
`docs/spec/modes.md`) used as a standalone code inside ordinary
English. Nothing about English changes; the frames are self-contained
phrases. All examples below are generated by `tools/modes.py` — they
are the real wire format, not illustrations.

## What you get

- **Density**: 4,207 is three syllables (*huu mi cin*) against ~ten
  in English.
- **Zero ambiguity**: no fifteen/fifty under noise; and dates carry
  no 08/14-vs-14/08 trap — *ho coon pu* is August 14th, period, in
  every country.
- **An optional integrity check**: a closing syllable that provably
  catches every single-symbol substitution and transposition within a
  legal frame. NOTE (2026-08-15 review): this is an algebraic property
  of the code, NOT a validated safety system — insertions, deletions,
  resegmentation, multi-error, noise, accent, and human-factors
  performance are all untested, and 87% of single-channel digit
  corruptions land on another valid digit before the checksum. No
  safety-critical use (dosages etc.) until a human-factors comparison
  beats ordinary digit-by-digit readback.

## The one-hour learning content

Digits ride syllables: **tens → consonant, units → vowel (+n for
5–9)**.

| digit | tens (onset) | units (rime) |
|---|---|---|
| 0 | c | a |
| 1 | p | e |
| 2 | t | i |
| 3 | k | o |
| 4 | m | u |
| 5 | n | an |
| 6 | s | en |
| 7 | l | in |
| 8 | w | on |
| 9 | j | un |

So 42 = *mi* (m=4, i=2), 07 = *cin*, 80 = *wa*. Frames open with an
h-word: *hu* number, *ho* date, *hi* time, *he* spelling; *hoos* +
one syllable closes with the checksum. Pronunciation for English
speakers: five pure vowels (ah eh ee oh oo), *c* = "ch", *j* = "y",
doubled vowels are just held a beat (or ignore the doubling — it's a
spelling-layer check mark).

## Honest costs

1. **Two-party convention.** Speech requires both sides to know the
   code (~1 hour). Written use degrades gracefully: a reader decodes
   with the table above on a card. Adoption path is therefore
   writing-first (confirmation codes, timestamps, invoices), speech
   second among practiced pairs.
2. It sounds like an incantation to outsiders — which is also its
   feature: frames are unmistakably not English, so they never
   collide with the host.
3. The doubling in the romanization (*huu*, *coon*) is a written
   check layer; casual speakers may flatten it with no loss (the
   checksum register exists for when loss matters).

## Why the frames embed so cleanly: the narrow-base advantage

English has ~40+ phonemes and Romance ~24–37; the mode syllables use
the greenfield's deliberately minimal 16 (11 consonants, 5 pure
vowels, open syllables + n/s codas). That narrowness — a cost when
building a whole lexicon (only 220 syllables) — is precisely what
makes the frames *portable*: every mode syllable is pronounceable by
speakers of nearly any L1, and inside English speech the frames'
clean CV rhythm is phonotactically conspicuous, which helps listeners
find the frame boundaries. Wide-inventory hosts and the narrow-band
code are complements, not competitors.

## Where this sits

This is the paper's §7 adoption-wedge claim made concrete: the mode
codes work inside a host language with no lexicon learning. If any
artifact of this project reaches strangers first, it is plausibly
this page plus a wallet card. A cheap next artifact: a `hu`-mode
input snippet (type digits, get syllables and back) — already
implemented in `tools/modes.py`; a phone keyboard or TextExpander
layer is trivial glue.
