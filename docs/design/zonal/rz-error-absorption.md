# Error-absorbing grammar (exploration, 2026-08-22, conlang-i78)

Premise: a learner's errors are as designable as their lessons. For
each documented top L2 error class (Romance-family SLA literature
[D — standard findings; verify against sources at paper-citation
time]), score what RZ already does, then price a menu of
**declarations** — spec sentences that reclassify a common error as
grammatical variation ("accent"), a move only an engineered
language can make. **ADOPTED D1-D7 (Edward, 2026-08-22)** — now normative in
rz-grammar.md §10. Calibration note from the ruling: decisions of
this class ("basically just a win, doesn't negatively affect
anything") may be called by the agent directly in future; the gate
is for real trades.

## 1. Scorecard: the classic error classes vs RZ v0.2

| 7 | false friends / lexical interference | **BOUGHT** — humility screen (existing) |

Seven of the fifteen classic traps are already unmakeable in RZ.
That is the regularity dividend stated in error space rather than
form space.

## 2. The declaration menu (priced; all ~0 learner-hours)

Precedent for the whole move: **spoken French already voices no
number agreement on most adjectives**, and no one calls spoken
French broken — variation tolerated by design reads as accent, not
error.

- **D1 — single negation = concord meaning.** `io vide nada` ≡
  `io no vide nada`. No ambiguity exists (`nada` cannot mean
  "something"). Concord stays the preferred register.
- **D2 — article omission is telegraphic register, not error.**
  `io vide tren` is grammatical and marked, like headline English.
  Buys the biggest single production hurdle of article-less L1s.
- **D3 — adjective number agreement optional.** `les organizaciones
  ambientales` (attested, stays preferred) and `les organizaciones
  ambientale` both grammatical. Spoken-French precedent above.
- **D4 — adjective position free; post-nominal is the default
  register.** `manto calde` ~ `calde manto`. Romance readers see
  poetry, English L1s see home.
- **D5 — clitic clusters: fill the v0.2 gap with the absorbing
  rule.** Max ONE preverbal clitic; a second object surfaces as
  full pronoun after the verb or a preposition (`io te dona le` /
  `io le dona a te`). No ordering rule to learn = no ordering
  errors to make. (Corpus already writes this way: zero clusters
  in the 628-token de-duplicated corpus.)
- **D6 — contractions optional.** `de le` ≡ `del`, `a le` ≡ `al`.
  Two fewer obligatory forms.
- **D7 — merge para → por.** The zone's most famous preposition
  trap deleted; `por` covers both, `para que` survives as a frozen
  subordinator if wanted. Corpus evidence: para has **zero**
  attestations in the 628-token corpus (por 2). Cost: Ibero readers find
  por-for-para slightly marked but fully comprehensible; gain: an
  entire error class gone. This one deletes an inventory item, so
  it is the largest call on the menu.

## 3. The principle

Natural languages cannot forgive their learners by decree;
engineered ones can. Where a channel can't cheaply *prevent* an
error, reclassify it: **an error that changes no truth conditions
and blocks no parse should be defined as variation.** The grammar
stays exactly as easy to read (every preferred form is unchanged),
and production anxiety — a real fluency tax [H, SLA literature] —
drops, because the learner's most probable deviations are all legal. This is the
learning-budget logic applied to the error side of the ledger:
absorption purchases are ~0 hours and cohort-targeted (each
declaration forgives a specific L1 family's signature error).
