# AZ-a Latinate twin table — seed (linter data)

Workshop draft (conlang-3ug). The controlled register's substance:
for each common English word/construction with weak Romance decode,
the preferred pan-Latinate twin. Column N = naturalness cost in
ordinary English (0 = none, 1 = slightly formal, 2 = stilted — spend
2s sparingly; the cloze numbers will price the dial).

## Non-lexical rules confirmed by drafting the samples

1. **No phrasal verbs** — the single highest-value rule; each one is
   an idiom a Romance reader cannot decode from parts.
2. **No idioms/metaphor in the controlled register**; metaphor is
   register-marked (literature can, documentation cannot).
3. **Prefer the of-genitive** where natural ("the minister of
   energy") — maps to Romance de-genitives; possessive 's stays legal
   (banning it costs naturalness, N=2, for marginal gain).
4. Germanic bedrock (sun, wind, water, day, house, hand, year…):
   keep — no common twins exist; the zone-overlap boundary is real
   and honest.
5. The twin must already be ordinary English (the `publicate` failure
   mode in the samples doc): this register is a *subset* of English,
   never a superset.
