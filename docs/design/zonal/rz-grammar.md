# RZ grammar reference — v0.2 (complete)

The full productive grammar. Design rationale lives in
`romance-zonal-v0.md`; this file is the reference a writer uses.
Everything here is recognition-first: where regularity and
pan-Romance naturalness conflicted, naturalness won (the adjective
lesson). Flags mark decisions the cloze data should revisit.

## 1. Sounds and spelling (recap)

Five vowels a e i o u (Latin values). `c`/`g` soften before e,i
(/ts/, /dʒ/ reference; L1 variants tolerated); `z` = /ts/ elsewhere;
`ni`/`li` = /ɲ/, /ʎ/ between vowels; `qu` = /k/ before e,i. No
silent letters, no accents. Contractions: only `del`, `al`. Stress:
penult if the word ends in a vowel or -s/-n, else final.

## 2. Nouns and determiners

- Plural `-s` / `-es` (after consonant). No case, no grammatical
  gender; natural gender in animate pairs (filio/filia).
- Articles: `le / les / un`. Demonstratives (two-way): `iste` (this),
  `aquel` (that), pluralized like adjectives: `istes, aqueles`.
- Possessives: `mi, tu, su, nostre, vostre, lor` (invariant).
- Quantifiers: `tote` (all), `multe` (much/many), `poc` (little/few),
  `alcun` (some), `necun` (no/none), `cata` (each), `altre` (other),
  `mesme` (same).

## 3. Pronouns

| | subject | object (preverbal) | after preposition |
|---|---|---|---|
| 1sg | io | me | me |
| 2sg | tu | te | te |
| 3sg m/f | el / ela | le / la | el / ela |
| 1pl | nos | nos | nos |
| 2pl | vos | vos | vos |
| 3pl m/f | eles / elas | les / las | eles / elas |

- Object pronouns stand **immediately before the verb they belong
  to**: `io te ama`; `io vole te veder` (= FR *je veux te voir*).
- Reflexive `se` (3rd person): `el se copriva`.
- Impersonal/general subject: `on` (FR on; reads via ES/IT *se*
  constructions): `on parla RZ aqui`. FLAG: `se`-impersonal may test
  better for Ibero readers.

## 4. Verbs (complete system)

Classes -ar/-er/-ir; person-invariant; subject pronouns obligatory.

| form | shape | example |
|---|---|---|
| present | stem+a/e/i | io parla, el vive |
| past | +va | el parlava |
| future | va + inf | nos va parlar |
| conditional | +ria | io parlaria |
| progressive | sta + gerund | el sta parlante |
| perfect-of-result | tener + participle | io tene parlate — FLAG: may read odd to IT/FR; alternative haber |
| participle | +te (-ate/-ite) | parlate, coprite |
| gerund | +nte | parlante |
| passive | es + participle (+ por agent) | es considerate por totes |
| imperative | bare present stem-form | Parla! / No parla! |

Irregulars (complete list, 3): `es/era/seria` (be), `va` (go, and
future auxiliary), `sta` (state/health, and progressive auxiliary).

4.1 **es vs sta** (codified after the reader-pack self-audit):
`es` = identity, property, definition (`el es medico`, `es libre` as
permanent character); `sta` = temporary state, location, health, and
the progressive (`el sta malade`, `le tren no stava ala`, `sta
parlante`). This is ser/estar simplified to a two-line rule. FLAG:
IT/FR readers (essere/être covers both) may find sta-for-location
marked; Ibero readers will find it exactly right; cloze will tell.
Past of `sta`: `stava` (regular -va on the sta stem).

## 5. Negation

`no` immediately before the verb (before object pronouns too?
**No — order is: `no` + object pronoun + verb**: `io no te
comprende`). **Negative concord is grammatical and preferred**, as
in the whole zone: `io no vide nada` (I saw nothing), `nunca` never,
`nadie`/`necun persona` nobody, `nada` nothing. (Recognition beats
logic; every source language does this.)

## 6. Questions

- Yes/no: statement order + rising intonation / `?`. No inversion,
  no do-support: `Tu comprende?`
- Question words fronted, no inversion: `que` (what), `qui` (who),
  `quando` (when), `donde` (where), `como` (how), `por que` (why),
  `cuante` (how much/many), `cual` (which).
  `Donde tu vive?` `Por que el partiva?`

## 7. Clauses

- Complement/relative: `que` universal: `io sabe que tu veniva`;
  `le libro que io lege`. Person-relative after preposition: `qui`
  (`le femina con qui io parlava`).
- Conditional: `si` + indicative: `si tu vole, nos va`.
- Common subordinators: `porque` (because), `quando` (when),
  `mentre` (while), `aunque` (although — FLAG: Ibero-heavy; IT
  *benché*, FR *bien que* lose), `despues que` (after), `antes que`
  (before).
- Comparison: `plus/minus ... que`; equality `tanto ... como`;
  superlative `le plus ...`.

## 8. Numbers

0–10: `zero, un, dos, tres, cuatro, cinco, ses, sete, octo, nove,
dece`.
11–15 (compromise forms, PT-closest): `onze, doze, treze, catorze,
quinze`. 16–19, transparent: `dece-ses, dece-sete, dece-octo,
dece-nove`.
Tens: `vinte, trenta, cuaranta, cincuenta, sesenta, setenta,
octanta, noventa`; compounds hyphenate: `vinte-un, trenta-dos`.
Hundreds: `cento, dos-centos …`; `mil`, `milion`, `miliarde`.
Ordinals: `prime, secunde, tercie, cuarte, quinte`, then
`numero + N` (`le numero ses`) — FLAG: higher ordinals diverge
across the zone; the escape hatch is deliberate.
Dates read naturally: `le catorze de agosto`, year as number:
`dos-mil-vinte-ses`.

## 9. Derivation (the regular families)

| affix | makes | example |
|---|---|---|
| -cion | action noun | crear → creacion |
| -itate | quality noun | national → nacionalitate |
| -mente | adverb | rapide → rapidemente |
| -al | adjective from noun | nacion → nacional |
| -or | agent | viajar → viajator |
| -ista | adherent/professional | arte → artista |
| -oso | full of | fama → famoso |
| -abile / -ibile | -able | leger → legibile |
| -ia | domain/state | economia |
| re- | again | releger |
| des- | undo/reverse | desfacer |
| in-/im- | negation (adjectives) | imposibile |
| pre-, sub-, super-, inter- | as in the international stock | internacional |

Rule: derivation never changes the base spelling; every derived form
must itself pass the false-friend screen.

## 10. Calendar

Days (planetary, pan-Romance): `lunedi, martedi, mercoledi, jovedi,
venerdi, sabato, dominica` — FLAG: Ibero drops -di (lunes, martes);
IT forms chosen for family regularity; test.
Months: `januario, februario, marzo, april, maio, junio, julio,
agosto, septembre, octobre, novembre, decembre`.
