# RZ number mode (tentatively adopted — Edward directive 2026-08-21,
# conlang-2yd)

RZ adopts the digit-pair number mode, zonal-variant codebook
(digit-codebook-v2.md). This deliberately crosses the line drawn in
gz-sketch.md ("RZ ends where live [h] begins"): RZ now carries one
engineered spoken subsystem.

## How it works in RZ

- **Frames live in the silent-h hole.** RZ's h is silent, so no
  Romance-derived word begins with [h] — the h-onset region is
  vacant and mode frames colonize it. [h] is *pronounced* in mode
  frames only: `hu` opens a number, aspirated. For h-dropping L1s
  (French), [h]~[x] is licensed and frames are prosodically marked;
  the careful register adds the checksum anyway.
- **Digits**: tens = zonal onsets (z v d t k c s p g n — six of ten
  guessable from Romance number words), units = the 10 spaced rimes
  (a un i an us in as u is al). 42: tens 4 = k, units 2 = i → the
  spoken number is `hu ki`.
- **Registers**: casual = bare digit syllables (phone number in ~half
  the syllables of speaking Romance number words); careful/readback
  = chunked with the separator particle + mod-101 checksum per chunk
  (residue-100 chunking rule, digit-codebook-v2.md).
- **Delimiting**: any non-h word ends nothing — the payload runs
  until the next [h]-onset or stressed content word; RZ's own words
  never start with [h], so the boundary is free, same as GF.
- Date/time modes: available by the same mechanism; deferred until
  the number mode survives a read-aloud test.

## What it costs a learner [D]/[H]

Frame particles (hu + separator + 2-3 more): minutes. Tens onsets:
6-7 guessable, 3-4 arbitrary. Units rimes: 10 arbitrary but short.
Checksum: careful register only, optional for casual use. [h]
production: the one real phonetic ask, and only inside frames.
Estimate: **~2h to casual competence, +2h for readback discipline**
[H — model estimate, zero subjects]. Recorded as a line item in
rz-learning-time.md.
