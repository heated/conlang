# Pricing: featural-script-primary vs Latin-primary for the zonal lang

**Question (Edward, 2026-08-09):** what does it cost in learning time to
make the wide chorded featural script the *primary* orthography of the
Romance zonal auxlang, versus Latin-primary with the featural script as
an optional input/display layer?

## The cost side

**1. Script acquisition, absolute.** Decoding a maximally regular
featural script is cheap — Hangul's featural design is learnable to
accurate decoding in hours-to-days, and ours is more regular (zero
exceptions, compositional). Estimate: **5–20 hours to accurate
decoding**. But decoding is not reading: fluent reading runs on a
whole-word visual lexicon, which a novel script resets to zero. The
closest measured anchor is Kolers' geometrically-transformed-text
experiments — even with the *same alphabet* merely rotated, adults
needed on the order of 50–100 pages of practice to approach normal
speed. A wholly novel script is slower. Estimate: **~50–100 hours of
reading practice to reach roughly half of natural-orthography speed;
hundreds of hours to near-parity.** [TODO-verify: Kolers 1975/1985
figures; adult L2 script-acquisition literature.]

**2. The bootstrap interaction — the real price.** The zonal value
proposition is *receptive intelligibility at first contact*: Interslavic
measured 84% cloze comprehension with zero study, and the survey's
strongest finding is that zonal langs grow by meeting readers in their
own orthography (Interslavic maintains dual Latin/Cyrillic precisely for
this). A featural-primary orthography does not degrade this mechanic —
it **severs** it:

| | Latin-primary | featural-primary |
|---|---|---|
| first-contact comprehension (Romance reader) | ~80%+ immediately | **0% until script learned** |
| time to first value | ~0 h | 5–20 h (decode) |
| time to comfortable reading | ~0 h | ~50–100 h |
| casual-visitor funnel | reads the homepage | hits a script wall |
| writer/contributor barrier | types today | script + input first |

The funnel effect can't be measured in advance, but the logic is brutal:
every mandatory pre-value hour multiplies top-of-funnel drop-off, and
5–20 hours before *any* comprehension plausibly costs one to two orders
of magnitude of casual conversion. Structurally, featural-primary
converts the zonal lang from a "read it today" product back into a
"learn a system first" product — **the Esperanto-shaped adoption profile
the zonal pivot exists to escape.** The survey also found writers are
the bottleneck for receptive languages; featural-primary raises the
writer barrier too.

## The benefit side (and where it survives Latin-primacy)

- **Orthographic transparency:** marginal here. Romance zonal
  orthographies are already near-phonemic (LFN fully; Interlingua
  mostly); the featural script's transparency win is large against
  English, small against them.
- **Chorded input speed:** *not gated on script primacy.* Chords are
  strokes over the phonology; they can emit Latin text. The entire
  input-speed win survives Latin-primary intact.
- **Silhouette skimming, POS visibility, dense text:** real, but
  display-layer features — available as an optional rendering.
- **Identity/aesthetics:** the one thing primacy uniquely buys, and it
  actively conflicts with the receptive bootstrap.

## Verdict

Featural-primary costs approximately **the entire zonal bootstrap
advantage** (84%-at-first-contact → 0-until-studied, plus a raised
writer barrier) and buys almost nothing that the layered configuration
doesn't also deliver. Priced answer:

- **Zonal lang: Latin-primary.** Wide chorded featural script ships as
  (a) the input method (chords → Latin text), (b) an optional dense
  display layer / "power reader" mode, (c) the enthusiast identity tier.
  Every win Edward wants from the script survives; the bootstrap does
  too.
- **Channel language: featural-primary stands.** It has no receptive
  bootstrap to lose — the script is part of its thesis and its
  learning-speed story targets a different audience.

If featural-primary for the zonal lang is still wanted despite this, the
honest framing is: it re-prices the zonal lang as an identity product
rather than a reach product, and the Interslavic-style growth mechanics
should not be expected to apply.
